# TEK-UP Code Club

Site web du TEK-UP Code Club (club de programmation fictif), construit pendant les TP HTML5 du module HTML5, CSS3, Bootstrap (ING-3-S5-P3).

## Contenu du TP 1

- `index.html` : page d'accueil
- `activites.html` : page des activités
- `inscription.html` : page d'inscription
- `images/` : dossier des images
- `a-corriger.html` : page de débogage corrigée
